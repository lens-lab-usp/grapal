Planejar uma semana difícil

Escolha o essencial, reduza o que for possível e identifique apoios. Este planejamento pode ser ajustado quando a semana mudar.

Todos os campos são opcionaisVersão para revisão
  1. Preencha apenas os campos que fizerem sentido. Não é preciso organizar toda a semana de uma vez.
  2. Comece com até três prioridades realistas e identifique o que pode esperar.
  3. Nos dias da semana, registre uma prioridade possível e um espaço para cuidado ou descanso.
  4. Se uma tarefa não couber, ajuste o plano. Use este roteiro para reconhecer limites e combinar ajuda.
Este é um espaço de anotação. O que você escrever não é enviado nem guardado pelo site. Para ficar com uma cópia, você pode imprimir ou salvar em PDF no seu dispositivo.

Dia a dia, com espaço para ajustes

Uma prioridade possível e um espaço para cuidado ou descanso. Deixe em branco os dias que ainda não quiser planejar.

As respostas não são enviadas ao GRAPAL, não são armazenadas pelo site e não são acompanhadas pela equipe. Para guardar uma cópia, use “Imprimir ou salvar PDF”. Se você sair ou recarregar a página, poderá perder o preenchimento.
