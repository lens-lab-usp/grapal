Todos os campos são opcionaisVersão para revisão
  1. Escolha as perguntas que ajudam você a começar. Deixar campos em branco é uma opção.
  2. Escreva com suas palavras: você não precisa saber o nome do que está sentindo.
  3. Se preferir, anote exemplos de situações recentes em vez de tentar explicar tudo.
  4. Este roteiro é opcional e não é um formulário de agendamento. Para marcar atendimento, use os canais oficiais do GRAPAL.
Este é um espaço de anotação. O que você escrever não é enviado nem guardado pelo site. Para ficar com uma cópia, você pode imprimir ou salvar em PDF no seu dispositivo.

Você não precisa ter respostas prontas para a consulta. Este material não agenda atendimento. As respostas não são enviadas ao GRAPAL, não são armazenadas pelo site e não são acompanhadas pela equipe. Para guardar uma cópia, use “Imprimir ou salvar PDF”. Se você sair ou recarregar a página, poderá perder o preenchimento.
